Every tile shares one hull substrate: the same chamfered deck plate, the same two panel seams at y=67 / y=189, half-connector plates centred on all six edges and half-nodes on all six vertices, so abutting tiles fuse into one continuous ship. Light reads from the top-left on every piece. 222×256 per tile.
Battle scarring — joint across n tiles
One scar per module, not per tile: a single crater, cracks that run across the seams into every other tile of the footprint, soot that thins with distance, pocks over the whole area, and old breaches plated over and bolted down. The layer sits above the module art and below the hex lighting pass, and is clipped to the union of the module's tiles so damage never bleeds into a neighbour. Deterministic per seed, so a scarred module stays scarred the same way.

Append-only tiers — the same wound, deepening
One two-tile module, one seed, four damage tiers. The scar never grows or re-rolls: every feature is generated once and tagged, and a tier only reveals more of the list, so tier 3 contains tier 1 and 2 exactly where the player last saw them. Scuffed is soot and grazes. Breached opens the hull and runs cracks across the seam. Patched bolts plates over those cracks. Veteran splits the patches, opens a second breach, and scatters more nicks.

Fresh hit → cooling → scar
One seed, one geometry, three heat values. The hot pass — bloom, molten rim, glowing core, thrown embers — is drawn from the same crater outline as the cold scar, so a hit can cool over a second or two without the damage shifting underneath it. Scar seeds come from game state (module instance id plus hit count), so the same module always carries the same history.

Conduits — automatic, function-coded wiring
Conduits are a lighter hex — open scaffold, no plating — that only ever carries wire between the reactor and modules. There is no assignment step: every module's circuit is fixed by what the module is. Weapons are always red, propulsion and flight control are always green, utility (sensors, tractor, cutter) is always blue. The layout below is computed, not hand-placed: each module's colour traces the shortest run of conduit hexes back to the reactor, so a shared trunk carries every colour its downstream modules need and only breaks into single-colour spurs at the junction where those modules actually diverge.
